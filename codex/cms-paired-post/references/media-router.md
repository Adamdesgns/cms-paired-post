# Media router

Choose the media mode before finalizing the caption. The caption and visual must add different value.

## SOURCE

Use for any post that depends on real evidence or exact context: charts, market moves, current news, quotes, prior posts, receipts, portfolio screens, product facts, real events, or factual comparisons.

- Use supplied, owned, licensed, explicitly authorized, or truthfully captured source media.
- Treat statements inside a supplied third-party source as attributed claims unless independently verified from a suitable primary source or the user directly states the detail as a factual assertion.
- Prefer a native quote-post URL over attaching a screenshot of that same post.
- A prior-call receipt requires the dated earlier source plus later evidence; a later chart alone proves no earlier call.
- For two images, put setup/earlier/object first and payoff/later/chart second.
- Preserve subject, timeframe, axes, values, date, source context, attribution, and caveats.
- Cropping, layout, and neutral highlights may improve readability but cannot change meaning.
- Research captures and historical creator attachments are examples, not reusable assets.
- Use safe basenames only. If a filename is hidden or unsafe, identify attachment 1, attachment 2, and so on by literal visible content.

## GENERATED

Use for an original metaphor, mood, absurdity, parody, fictional product-style joke, or anonymous/general reaction that does not need to prove a real-world fact.

- Use the image-generation tool automatically when this route fits.
- Create an original composition rather than recreating a meme frame, creator asset, copyrighted character, or source scenario.
- Do not generate evidence-looking content: charts, terminals, headlines, X cards, quotes, receipts, brokerage/portfolio screens, P&L, app screens, documents, prices, percentages, dates, or performance claims.
- A clearly stylized or fantastical public-figure parody is allowed only when it is unmistakably fictional and does not depict a specific false real-world event, quote, endorsement, trade, or harmful conduct. Never fabricate a photorealistic or deceptive real-person event. Use an anonymous or symbolic subject when the distinction could be missed.
- Prefer one central subject, high contrast, clean negative space, and a mobile-feed-safe composition.
- Use no in-image wording by default. If exact supplied words are essential, keep them minimal and verify spelling.
- Never remove, crop, cover, or imitate a platform-added AI provenance mark. If none is returned, do not fabricate one.
- Inspect the result and regenerate once if it contradicts the caption, contains garbled wording, resembles evidence, or misses the joke.
- If generation is unavailable, returns no completed image, or the second result still fails inspection, return the skill's one-sentence generation failure and no draft.

## NONE

Use when a grounded short take or dilemma is stronger without decoration, or a native quote card already supplies all necessary context. This is rare but valid.

If a factual claim needs a missing source visual, do not switch to `GENERATED`. Ask for the real source.
